# Security

The tool handles your vault, so its security properties are listed in [AGENTS.md](AGENTS.md#invariants-do-not-break) and in the README.

To report a vulnerability, use GitHub's private vulnerability reporting (Security tab, "Report a vulnerability") rather than a public issue. The project is not actively maintained, so there is no guaranteed response time; a public advisory may be the fastest way to warn other users.

Never paste vault data, reports or the work file into an issue.
