# Contributing

This project is shared as is and is probably not going to be maintained. Issues and pull requests may stay unanswered.

The best way to improve it is to fork it: the code is in the public domain ([Unlicense](LICENSE)).

If you still open a pull request:
- read [AGENTS.md](AGENTS.md), in particular the invariants;
- keep the standard-library-only rule;
- run `python -m unittest discover -s tests -v`;
- update `docs/USAGE.md` when behavior changes.
